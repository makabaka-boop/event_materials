# 活动物资管理工作台 PRD

## 1. 产品概述

活动物资管理工作台是一个纯前端的单页面工具，用于活动筹备阶段整理物资清单、分组领取、缺口提醒和现场核对。目标用户为活动组织者单人使用，无需登录和权限管理，所有数据保存在浏览器 localStorage 中。

- 主要用途：物资清单 CRUD、分组领取管理、异常自动检测、现场快速核对
- 价值：解决活动物资管理中清单分散、核对困难、遗漏责任人和缺口发现不及时的问题

## 2. 核心功能

### 2.1 功能模块

单页面应用，包含三个主要区域：

1. **顶部筛选区**：活动筛选、小组筛选、状态筛选、现场核对模式切换、快速新增按钮
2. **中央清单区**：物资表格列表、全选/多选、批量操作栏、行内编辑
3. **右侧详情面板**：点击物资行滑出，展示完整信息，支持备注编辑和详情修改

### 2.2 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 物资清单页 | 顶部筛选区 | 活动下拉筛选、小组下拉筛选、状态多选筛选、搜索框、"现场核对模式"开关、"+ 新增物资"按钮；筛选条件变化时，若有已选中的记录不在新筛选结果中，显示提示横幅 |
| 物资清单页 | 中央清单区 | 表格展示：复选框、物资名称、分类、活动、预计/实际数量、小组、责任人、状态标签、异常标记；支持行内快速编辑数量和状态；表头全选框仅选中当前筛选结果内的记录；底部显示统计汇总 |
| 物资清单页 | 批量操作栏 | 选中记录后浮现在表格顶部：批量设置状态、批量分配小组、批量设置责任人、清除选择；操作前提示"将作用于 N 条已选中记录" |
| 物资清单页 | 右侧详情面板 | 点击行滑出抽屉式面板：展示所有字段完整编辑表单，包含大段备注输入框、异常提示列表、"保存"和"删除"按钮 |
| 物资清单页 | 新增物资弹窗 | 点击"+ 新增"打开：名称、分类、活动、预计数量必填；支持快速连续添加 |

### 2.3 数据字段定义

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | string | 唯一标识，自动生成 |
| name | string | 物资名称 |
| category | string | 分类（如宣传品、餐饮、设备等） |
| activity | string | 所属活动名称 |
| expectedQty | number | 预计数量 |
| actualQty | number | 实际数量 |
| group | string | 领取小组 |
| owner | string | 责任人 |
| status | enum | 待准备/待领取/部分领取/已领取/缺口待补/暂缓 |
| remark | string | 备注 |
| createdAt | number | 创建时间戳 |
| updatedAt | number | 更新时间戳 |

### 2.4 自动检测异常规则

系统实时检测并标记以下问题：

1. **数量缺口**：actualQty < expectedQty（非0时触发）
2. **责任人为空**：owner 为空字符串
3. **同名重复**：同一 activity 下存在多条同名 name 的记录
4. **领取异常**：status === "已领取" 但 actualQty === 0
5. **备注异常**：remark 包含"缺"、"少"、"忘"、"错"等关键词时标记

每条异常记录在行内显示警告图标，点击可查看具体原因。

### 2.5 现场核对模式

切换"现场核对模式"开关后：

- 仅显示存在异常的条目（缺口、待领取、备注异常）
- 清单样式变为紧凑的核对清单样式
- 每条记录旁显示"✓ 已核对"快速按钮
- 适合现场逐项核对使用

## 3. 核心流程

### 3.1 主要用户流程

用户打开页面后，数据从 localStorage 自动加载。流程包括：准备物资清单、分配小组和责任人、批量标记领取状态、现场核对。

```mermaid
flowchart TD
    "A[打开工作台]" --> "B[加载 localStorage 数据]"
    B --> "C{是否有数据?}"
    C -->|否| "D[空白清单，引导新增]"
    C -->|是| "E[渲染清单列表]"
    D --> F["+ 新增物资"]
    E --> F
    F --> G["填写物资信息"]
    G --> H["保存到 localStorage"]
    H --> I{"需要批量操作?"}
    I -->|是| J["勾选多条记录"]
    J --> K["选择批量操作"]
    K --> L["确认操作范围提示"]
    L --> M["批量更新并保存"]
    I -->|否| N{"需要筛选?"}
    M --> N
    N -->|是| O["选择筛选条件"]
    O --> P{"有被隐藏的勾选记录?"}
    P -->|是| Q["显示提示横幅"]
    P -->|否| R["更新清单显示"]
    Q --> R
    N -->|否| S{"现场核对?"}
    R --> S
    S -->|是| T["开启现场核对模式"]
    T --> U["仅显示异常条目"]
    U --> V["逐项核对标记"]
    S -->|否| W["继续编辑"]
    V --> W
    W --> X["数据自动保存 localStorage"]
```

### 3.2 批量操作边界规则（关键）

1. **勾选独立于筛选**：选中集合是全局的，不随筛选变化而清空
2. **筛选变化提示**：切换筛选后，若存在"已选中但不在当前筛选结果中"的记录，顶部显示橙色提示条："当前筛选结果外还有 N 条已选中记录，批量操作将影响所有 N 条记录"
3. **全选范围**：表头全选框只选中/取消选中"当前筛选结果内"的记录，不影响筛选外已选中的记录
4. **批量操作确认**：执行批量操作前，弹窗明确告知操作的总条数（包含筛选外被隐藏的选中项），用户确认后才执行

## 4. 用户界面设计

### 4.1 设计风格

- **配色方案**：主色调采用沉稳的深墨蓝 (#1e3a5f)，辅助色用暖琥珀色 (#f59e0b) 作为警告色，成功色用翠绿 (#10b981)，错误色用砖红 (#ef4444)。背景为浅灰白 (#f8fafc)，卡片纯白 (#ffffff)。
- **按钮风格**：圆角 8px，主按钮实心填充，次要按钮描边风格，hover 有微上浮动效
- **字体**：标题使用 "Noto Sans SC" 500 字重，正文使用系统无衬线字体，数字等宽显示便于对比数量
- **布局风格**：三区域极简布局（顶部筛选条 + 中央清单表格 + 右侧抽屉面板），卡片阴影克制，大量留白，信息密度适中偏高（工作台风格）
- **图标风格**：使用简洁的 Lucide 风格线性图标，异常用琥珀色三角警告标
- **状态标签**：不同状态用不同底色的小圆角标签：待准备(灰)、待领取(蓝)、部分领取(琥珀)、已领取(绿)、缺口待补(红)、暂缓(紫)

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|

### 4.3 响应式设计

桌面优先设计（最小宽度 1024px）。在较小屏幕上：
- 右侧面板改为全屏覆盖
- 表格部分列可横向滚动
- 筛选区换行显示

### 4.4 微交互

- 新增/保存成功：行项高亮闪烁一次绿色背景
- 状态变更：标签颜色过渡动画 200ms
- 抽屉面板：滑入动画 300ms ease-out
- 批量操作确认：弹窗缩放淡入 200ms
- 异常标记：警告图标轻微呼吸动画
